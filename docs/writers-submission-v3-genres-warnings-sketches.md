# Fosgen / Writers Submission — анкета v3

## Что изменено

### Все новые заявки

**Основные жанры:** 1–3 уникальных значения по 70 символов, три отдельных поля
с тремя сегментами прогресса. Публикация размещает жанры *сразу после
описания* в виде:

`• Романтика • Детектив • Путешествие во времени •`

**Предупреждения:** обязательный выбор «Нет» либо «Да».
После «Да» появляется обязательное поле для списка из 1–10 уникальных
предупреждений (до 85 символов в одном). Предупреждения вводятся через
запятую или с новой строки. При выборе «Нет» список не нужен.
Для публикации применяется формат:

```
🚨 ПРЕДУПРЕЖДЕНИЯ (18+)
× Самоубийство × Насилие × ...
```

Данные выводятся как экранированный HTML и не могут внедрить
Telegram-разметку в карточку.

**Описание больших работ (ФФ и Оридж):** не менее 3 завершенных
предложений (проверяется завершающая пунктуация) и не более 110 слов.
Размер в символах по-прежнему ограничен на уровне хранилища.

### Зарисовка

Третий тип работы **«Зарисовка»**. Отдельные поля:

1. Название.
2. Короткое описание **до 35 слов и 230 символов**. Это приблизительно
   три короткие строки Telegram; точная разбивка зависит от ширины экрана,
   шрифта, HTML-разметки.
3. Ссылка HTTPS на профиль автора на `ficbook.net`.
4. Ссылка HTTPS на статью в `telegra.ph` с полным текстом зарисовки.
5. Фандом либо Ориджинал. При выборе Фандом нужно указать название.
6. Направление.
7. Рейтинг.
8. 1–3 основных жанра.
9. Обязательный выбор по предупреждениям и список при выборе «Да».

Поля объема, статуса, дополнительных ссылок, персонажей, примечаний,
загрузки своей обложки и редактора большого произведения скрываются
для зарисовки. Режим обложки фиксируется как `editorial`. Вместо
пользовательского макета выводится информация, что обложку рубрики
делает команда ИКФ. Формирование самих редакционных обложек
автоматически не запускается.

В посте публикуются `#Фандом` (включая название фандома) или
`#Ориджинал`, `#Рейтинг`, `#Направление`, жанры, предупреждения,
ссылка на профиль Фикбука и ссылка на статью Telegraph.

## Совместимость

Форма помечается версией `form_version: 3`.
Валидация при сохранении черновика разрешает неполную анкету,
а отправка на модерацию строго перепроверяет жанры,
предупреждения, тип и длину описания на сервере PostgreSQL.
**Нельзя обойти лимиты удалением клиентской JavaScript-проверки.**

Старые версии `form_version: 2` остаются доступными для чтения.
При открытии старого черновика в обновленном Mini App он редактируется
по новой версии и должен пройти новые проверки до отправки.
Изменять уже опубликованные работы автоматической миграцией не нужно.

Файл `writers_submission/static/app.js` и CSS получают обновленный
cache-busting URL для Android/iOS Telegram WebView.

Новых ENV и ручных миграций нет: новые поля сохраняются в существующем
`details_json`. Не удаляйте PostgreSQL-данные при развертывании.

## Проверки

- Валидация жанров 0/1/3/4, дубликатов.
- Принудительный ответ «Да»/«Нет», список при «Да», HTML-экранирование.
- Короткое и длинное описание, граничные ограничения.
- Зарисовки: HTTPS Ficbook/Telegraph, происхождение, редакционная
  обложка, рубричные хештеги, отдельные ссылки.
- Сохранение незавершенного черновика, обратная совместимость v2,
  существующие загрузки файлов, PostgreSQL и Bothost Docker.
