# Fosgen v5.5 — локальные мемы сообщества и редкие эмоции

Реализовано по обсуждению в ИКФ 15 октября, когда участники несколько минут
цитировали «внеплановые овации», смеялись над шутками Фосгена и продолжали
сюжет между собой.

## Что меняется

- При живом ответе на шутку Фосген **иногда** (около 24% случаев сильного
  смеха в подходящих прямых диалогах) выбирает собственную
  короткую смешную реакцию с капсовым «АХАХА/ПХАХА». Рядом остаются
  обычные спокойные шутки. Если недавно уже смеялся капсом — повторно
  не кричит. Все сообщения проходят обычный фильтр безопасности.
- Локальные мемы извлекаются **исключительно из проверенных прошлых реплик
  самого бота** в текущем чате и топике. Для признания шутки популярной
  необходимо минимум **две реакции разных людей**, сохранившиеся
  в Culture Memory. Учитываются прямой ответ со смехом и точное
  совпадение двух достаточно необычных слов в цитате.
- Реакции приписываются ботской фразе лишь в течение 20 минут после
  ее появления. Один участник может дать не больше одного голоса.
  Пересылки, сообщения других ботов и команды не учитываются.
- При прямом Telegram-ответе на Фосгена, содержащем узнаваемую
  отсылку («внеплановые овации», «помнишь тот мем?»), и после
  30 минут с последней реакции он **может** напомнить собственную
  памятную фразу. При отсутствии надежного соответствия выбирает
  обычный ответ или молчит. Никаких случайных цитат в непричастных темах.
- Данные хранятся уже существующими механизмами Actions и Culture Memory
  в PostgreSQL/SQLite. Счет популярности вычисляется из текущих
  consented событий, **не сохраняется отдельно**: удаление воспоминаний
  участника исключает и его голос из мемов.
- Ради производительности используем максимум 360 действий за 7 дней
  и 1500 последних Culture Memory событий, поиск соответствий
  оптимизирован по времени действий. История мемов ограничена
  доступным сроком и глубиной данных; это не безусловная вечная память.
- Не храним цитаты человеческих сообщений в metadata бота,
  не выводим чужие ID и имена в текст, не пользуемся внешними
  ИИ API или токенами.

## Что не меняется

- Общие лимиты и кулдауны, четырехшаговый диалоговый предел,
  часы тишины, настройки выбора поведения, безопасность,
  сообщения вне разрешенных топиков и память с правом отказа.
- Мемные отсылки не инициируют **новые автономные сообщения** вне
  существующего механизма: пока это только контекстные прямые ответы.
- Новых SQL-таблиц, ENV, внешних зависимостей не требуется.

## Проверка на Bothost

1. Пересобрать бота из main, сохранив PostgreSQL.
2. Ответить на его текст сильным смехом несколько раз (не чаще
   установленных лимитов). Капс-реакции должны быть **редкими**, не подряд.
3. Для теста мем-памяти дождаться, пока два разных участника
   отреагируют на одну его шутку в одном топике. Спустя более
   30 минут напрямую ответить боту, упомянув заметную часть фразы.
   Бот может напомнить собственную реплику; без двух голосов
   этого происходить не должно.
4. Убедиться, что удаление Culture Memory/отказ от запоминания
   убирают соответствующий голос в тесте.
5. Переотправка того же Telegram обновления не должна порождать
   дубли, четыре последовательных ответа остаются пределом.

Тесты: `tests/test_entertainment_meme_memory.py`,
`tests/test_entertainment_dialogue.py` плюс остальная регрессия.
