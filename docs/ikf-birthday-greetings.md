# Поздравления Фосгена с днем рождения

Общий лимит — одно поздравление с днем рождения на весь чат за календарный
день по Москве. Все темы, адресные планы и обычные реакции делят одну запись
в БД; перезапуск и другие реплики бота лимит не сбрасывают.

Первое человеческое «с днем рождения» запускает одно теплое поздравление
Фосгена. Повторные поздравления любого участника в любых темах этого же чата
не создают дополнительных сообщений. Учитываются только свежие сообщения текущего московского
дня, включая подписи к фото; боты, пересылки и поздравления с другими событиями
не запускают деньрожденную реакцию. Поддерживаются «с днем рождения», «с др»,
«сдр», «с днюхой», «с днем варенья» и Happy birthday.
Обычные реакции учитывают выключенный `/fun`, запрет автономного текста и тихие
часы. Адресный план, который администратор явно согласовал, остается исключением.

Тексты состоят из цельных авторских вступлений, пожеланий и завершений:
2304 комбинации без разрыва слов эмодзи или копирования сообщений из памяти.
На разных днях вступления сменяются, а выбор сохраняется при перезапуске.

Одноразовые планы хранятся в `entertainment/birthday_plans.json`, внутри
пакета приложения, а не в каталоге runtime-данных `/app/data`. Для запуска
нужно развернуть эту версию бота и оставить процесс работающим. Изменять
переменные окружения или вручную запускать миграцию не требуется.

Текущий согласованный план: @Buketsireni, чат ИКФ `-1002619489118`,
3 ноября 2026 года, 12:30 Europe/Moscow. Текст основан на выбранном
пользователем теплом варианте 1 и его описании «сказочница». Первое имя,
возраст, личные заявки и названия непубличных работ не используются.

На эту дату бот может присоединиться раньше к поздравлению от человека,
если тот упомянул точный @username или ответил на сообщение именинницы.
Общее «с днем рождения», поздравление другому участнику, неоднозначный список
получателей, бот или пересланное сообщение раннюю отправку не вызывают.
Ответ имениннице с явным поздравлением другому человеку также не подходит.
На дату адресного плана общий слот зарезервирован для него: обычный движ
с поздравлениями не создаст второго сообщения и не вытеснит согласованный текст.
Запрещенные развлекательные темы сохраняют свое ограничение.

Если ранней отправки не было, минутный supervisor отправляет поздравление
первым тиком после 12:30. Обычная случайная активность, лень и отсутствие
свежих сообщений для этого не требуются. Используется только настроенный
allowlist чатов. План не повторяется ежегодно. При позднем запуске в тот же
день бот догоняет расписание; со следующего календарного дня план истекает.

Таблица `entertainment_birthday_delivery` создается автоматически в PostgreSQL
и SQLite. До обращения к Telegram сохраняется уникальная заявка на отправку
по `(chat_id, local_date)`. Адресная реакция, общий движ и таймер делят
одну запись. После успеха сохраняются `SENT` и Telegram message ID.
После ожидания БД дата проверяется заново: просроченное поздравление не уходит.
При переходе через полночь дата успешной доставки берется из ответа Telegram.

Подтвержденный отказ Bot API освобождает запись для следующей попытки.
При сетевом timeout, серверной ошибке Telegram или потерянном ответе статус
становится `UNCERTAIN`; бот не отправляет поздравление повторно вслепую.
Если процесс остановился во время отправки, может остаться `CLAIMED`.
Эти два статуса требуют сверки с чатом и блокируют новые поздравления этого
чата, включая следующие сутки, пока прежний исход не подтвержден: API Telegram не дает гарантии
exactly-once при потере ответа. Удалять запись для повтора можно только
после ручной проверки, что поздравление действительно не появилось.
Если оно появилось, нужно подтвердить `SENT`, Telegram message ID и его реальную
московскую дату вместо удаления строки. История подтвержденных доставок не
должна очищаться для восстановления неопределенной попытки.

Диагностика: `BIRTHDAY_DELIVERY_SENT`, `BIRTHDAY_DELIVERY_REJECTED`,
`BIRTHDAY_DELIVERY_UNCERTAIN`, `BIRTHDAY_DELIVERY_STORAGE_FAILED` и
`BIRTHDAY_PLANS_LOAD_FAILED`. Репозиторий и тесты подтверждают готовность кода;
факт доставки подтверждается Telegram message ID и сообщением в чате.
