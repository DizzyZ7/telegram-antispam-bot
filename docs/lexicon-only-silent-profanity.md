# Антимат с шуточным предупреждением для чата Лексикона

Чат: `-1002659916114`. Включена **только** беззвучная проверка текста и
подписей к фото/файлам по существующему словарю
`writers_moderation.contains_prohibited_language`, включая маскировку
(`бл*ть`, `п***ц`, `н*хуя`). Обнаруженные сообщения удаляются.

**После успешного удаления** Фосген показывает короткое сказочное
предупреждение про фей и «50 кроко» — это шутка, никакого реального штрафа
или ограничения нет. **Не чаще одного сообщения на весь чат за 90 секунд**,
даже если мат удален у нескольких участников. Остальные удаления в пределах
интервала происходят молча, без повторного предупреждения.

Если удалить сообщение не удалось, бот отмечает это в логах, предупреждение
не отправляет и сообщение не засчитывает как игровое слово.
Остальные приветствия, старые модерационные предупреждения, антиспам и
развлекательные сообщения по-прежнему отключены.

Реализация: `SilentLexiconProfanityMiddleware` — внешняя middleware для
`message` только в указанном чате. Она регистрируется **раньше**
`MiniGameGuessMiddleware`, чтобы мат не засчитывался как игровая догадка.
Нормальные сообщения, команды Лексикона и корректные ответы игры проходят
без изменений. Другие модерационные механизмы, антиспам-сообщения,
приветствия, статистика и Entertainment не включаются. Группа **не
добавляется** в `ALLOWED_CHATS`; старый `lexicon_only_chat_guard`
сохраняется.

Три исключения из фильтра **писательского** форума (`14637`,
`42817`, `292358`) не изменяются. Они относятся только к другому
чату `-1002619489118`.

## После выкладки

1. Добавить Фосгена `@Fosgen_AntiSpam_bot` в чат `-1002659916114`
   администратором и дать ему право **Удаление сообщений**.
2. Если Telegram privacy mode не позволяет боту получать обычные сообщения
   группы, отключить `Group Privacy` у бота через BotFather и
   **пере-добавить** бота в группу (либо проверить получение сообщений
   после изменения настройки). Без обновлений Telegram фильтр не
   сможет удалить мат.
3. Пересобрать latest `main` в Bothost; новых ENV не нужно.
4. Проверить два сообщения обычным аккаунтом: текст с матом должен исчезнуть
   с одним шуточным предупреждением**; повторное удаление в ближайшие
   90 секунд пройдет молча. Нейтральные сообщения и команды Лексикона
   работают по-прежнему. Проверить также подпись фото, если нужно.
5. Лог `LEXICON_PROFANITY_FAIRY_NOTICE_READY` подтверждает подключение
   middleware. Лог `LEXICON_PROFANITY_DELETE_PERMISSION_READY` подтверждает
   права бота; `LEXICON_PROFANITY_DELETE_FAILED` указывает проблему удаления.

Никаких изменений PostgreSQL или правил защиты частных вложений ИКФ нет.
