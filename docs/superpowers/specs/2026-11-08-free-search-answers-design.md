# Короткие ответы Фосгена через бесплатный поиск

Согласовано в переписке 08.11.2026: пользователь выбрал пробу Tavily, обязательную бесплатность, короткий текст в чате и точный запасной ответ «Пу пу пу».

## Цель и подход

Отвечать на явные вопросы «Фосген, что такое ...», «Фосген а почему ...» через Tavily Search с готовым кратким ответом. Существующая накопительная развлекательная речь остается локальной. Рассмотрены: Google/Gemini с ограничениями бесплатного отображения; отдельный бесплатный поисковик и языковая модель; Tavily с готовым ответом. Выбран последний вариант: один бесплатный ключ и один внешний запрос, без дополнительной модели.

## Контракт

- Включается только при непустом TAVILY_API_KEY. Аккаунт Tavily остается на Researcher Free, без карты и pay-as-you-go; код не меняет подписку и не использует другие платные сервисы.
- Один API-вызов: search_depth=basic, auto_parameters=false, include_answer=basic, max_results=3, language=ru, safe_search=true. Стоимость базового запроса по текущей документации — один кредит; 1000 бесплатных кредитов в месяц делятся на аккаунт. При нехватке квоты — отказ, без повторных запросов.
- Один вопрос — максимум одно сообщение. Обычный ответ содержит до 700 символов; завершенный краткий ответ, обычно 2–4 предложения. Длинный ответ не обрезается и не дробится; используется запасной ответ.
- Ошибка, таймаут, пустой/непригодный результат, слишком длинный ответ, неподдержанный формат, небезопасный текст или исчерпание ограничений: ровно «Пу пу пу», без точки и эмодзи.
- Принимается только непустой русский ответ с непустыми релевантными поисковыми результатами и достаточным совпадением значимых слов ответа и найденных материалов; также проверяется связь с вопросом. Это консервативная лексическая проверка, которая может отклонять перефразировки и переводы. Это уменьшает выдумки, но не является гарантией истинности. Точность и русский язык нужно отдельно проверить на 20–30 вопросах после получения ключа; до этого не заявлять проверку реального поиска.
- Внешний запрос не содержит историю чата, Telegram ID, имен пользователей или данные памяти; только текст явно адресованного вопроса, до 500 символов.
- Существующие ограничения чатов/тем, /fun_off, выключение текста и тихие часы сохраняются. Пересылки, боты, команды и вопросы с небезопасным текстом не отправляются провайдеру.
- Поисковый обработчик стоит после модерации. Его вопросы не запускают параллельный развлекательный ответ и не попадают в память через фоновую очередь.
- Таймаут HTTP — 5 секунд, до начала доставки — 7 секунд; доставка Telegram имеет отдельный предел 5 секунд. Ответ HTTP ограничен 128 КиБ; редиректы запрещены, адрес API фиксирован. Ключ — только заголовок Authorization, не журналируется.
- Дедупликация в SQLite/PostgreSQL атомарным claim в существующей таблице ent_actions, частичный уникальный индекс для search_reply по chat_id+trigger_message_id. Claim до внешнего запроса/отправки; если право на отправку не подтверждено из-за ошибки БД, сохраняется молчание: при неопределенной доставке повторная отправка не выполняется. Новых таблиц/зависимостей нет.
- Не больше одного активного поиска в процессе; повторный вопрос пользователя в течение 30 секунд получает запасной ответ без обращения к API. Счетчики и идентификаторы ограничены памятью процесса. Технические логи содержат только категорию отказа, без запросов, ответов, ключей и телеграм-идентификаторов.

## Проверка и включение

Тесты: локальный HTTP-сервер вместо Tavily, ошибки/неверные данные/таймауты, реальная SQLite с повторным открытием, PostgreSQL CI, изоляция тем, приоритет модерации и маршрутизация через экспортируемый EntertainmentService. Полный Python/Node набор, сборка контейнера и одно независимое ревью.

Для активации владелец создает бесплатный аккаунт на app.tavily.com и добавляет TAVILY_API_KEY в Bothost. Настоящий ключ, вход в аккаунт и боевой запрос не входят в офлайн-проверки. Первоначально ключ не настроен.
