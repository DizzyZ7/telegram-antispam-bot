# Graphics v3: план и журнал доказательств

Цель: премиальные объемные плюшевые питомцы всех 12 видов с локальной
детерминированной кастомизацией, без изменения любого сохраненного питомца.
Основа ветки: main 0c9b1d7. Отдельная ветка feat/fosgen-pets-graphics-v3;
разработка шашек в PR #129 не включается и не редактируется.

## Выбор архитектуры

Текущие контурные SVG v2 дают хорошие крупные цветовые вариации, но не нужный
плюшевый материал. Чистый SVG потребовал бы имитировать ворс и сложную светотень
сотнями дополнительных фигур. Полноценный 3D-движок усложнил бы production.

Выбран гибрид: оригинальные нейтральные видовые растровые основы, созданные
однократно для проекта, + локальные процедурные поля окраса и света, маски
мордочки/глаз и согласованная мягкая деформация. Pillow/NumPy работают на CPU.
При создании питомца нет внешнего запроса, модели, GPU или случайной генерации
ассета. Исходные основы замораживаются и проверяются по SHA256. v3 сохраняет
самостоятельный SVG с embedded PNG и исходный PNG, а не внешний ресурс.

## Контракт сохранности

v1/v2 DNA, SVG, golden fixtures и сохраненные портреты не изменяются.
CURRENT_ASSET_VERSION остается 2. Lab может явно запросить 3, но production
переходит на 3 только после художественного одобрения пользователем и двух
явных настроек; ни одна из них не выставляется этим PR автоматически.
Миграция, перерисовывающая существующие портреты, не предусмотрена.

## Художественный контроль

Техническое прохождение не означает, что стиль одобрен владельцем.
Критерии: узнаваемая анатомия каждого вида, мягкие объемные лица и материал,
естественные окрасы, дружелюбный взгляд, целый силуэт и читаемость 128 px.
Однотонные окрасы не получают крупных искусственных пятен ради метрик;
для них высокое сходство допустимо. Ветка не сливается до оценки PNG владельцем.

## Результаты

15 ноября 2026:

- Исходный main: 1199 тестов, OK, 99 пропусков без TEST_DATABASE_URL.
- Полный финальный прогон: 1270 тестов, OK, без пропусков, 68,474 s. Свежий
  временный PostgreSQL 16.2; production БД не использовалась. CI дополнительно
  проверяет PostgreSQL 17 и Docker.
- Node: 65 тестов, 65 pass. Python compileall и git diff --check прошли.
- Старые DNA/15 PNG/SVG сверены с main; v1/v2 golden не изменены. Новые
  PNG/RGBA golden фиксируют все 12 видов v3, проверены реальным рендером.
- 204 PNG и 144 сравнения: одинаковых visible RGB в выборке нет. 90 seed-пар
  и 42 пары редких отметин не совпадают. Это конечная выборка, а не доказательство
  глобальной уникальности.
- SSIM по 15 парам каждой серии: tabby 0,876–0,927; tortoiseshell 0,853–0,896;
  puppy spotted 0,857–0,898; badger mask 0,851–0,948; foal dapple 0,929–0,978;
  arctic solid 0,934–0,995. Для solid близость намеренно допустима.
- Измерение 24 портретов, 2 потока: 1,816 s wall; среднее 0,146 s;
  p95 0,199 s; пик всего процесса 127,3 MiB, PNG 100–175 KiB. Полные версии
  и машина записаны в performance.json. Это локальная характеристика, не SLA
  тарифа Bothost. Потолок smoke-теста 320 MiB проверяется в отдельном процессе.
- Найденные при просмотре дефекты исправлены с регрессиями: отметина между
  длинными ушами, пропадающая веснушка на белом мехе, светлый ореол у ноздрей
  темного жеребенка, seed-вариация оттенка радужки.
- В тесте ресурсов воспроизведено наследование Linux getrusage high-water от
  родителя через exec; замер заменен на VmHWM текущего адресного пространства,
  после чего весь прогон повторен успешно. Порог памяти не повышался.
- Независимый просмотр нашел дефекты ореолов/контраста, исправленные выше.
  Ревью путей хранения/выдачи не нашло регрессии сохраненных портретов.

Результат удаленного CI отображается в Checks отдельного PR. Он также
публикует полный набор PNG/HTML/DNA/метрик как artifact. Художественное
утверждение владельцем остается обязательным.
Draft PR не означает разрешение на слияние или включение v3 в production.
