# Зарисовки: мини/драббл и сборник драбблов

В форме «Зарисовка» после выбора происхождения появляется обязательное поле **Размер зарисовки** с двумя взаимоисключающими вариантами:

- **Мини/драббл** — достаточно ссылки на профиль автора на Фикбуке и статьи с текстом зарисовки в Telegraph.
- **Сборник драбблов** — дополнительно запрашивается ссылка на сам сборник на Фикбуке (HTTPS `ficbook.net/readfic/...`). Поле показывается **под профилем автора**, а статья подписывается **«Статья с текстом зарисовки в Telegraph (один из драбблов сборника)»**.

Если автор переключился со сборника на одиночный драббл, ранее введенная ссылка на сборник сохраняется в поле формы до переключения назад, но **не отправляется** в сохраняемые сведения для одиночного варианта.

На сервере добавлены `details.sketch_size` и `details.sketch_collection_url` (без миграции PostgreSQL, так как это расширение JSON-данных заявки). Для сборника ссылка должна вести именно на произведение `/readfic/...`, не на профиль. В черновиках допускается неполная ссылка; строгая проверка включается при подаче на модерацию.

Для ранее созданных зарисовок без размера форма автоматически выбирает «Мини/драббл» при повторном открытии. В старых публикационных предпросмотрах отсутствующий размер интерпретируется как одиночный.

В карточке модератора и готовом посте порядок ссылок одинаков: **профиль на Фикбуке → сборник драбблов (для соответствующего размера) → Telegraph**. Дополнительная ссылка не появляется для одиночной зарисовки. Формат кавычек, спойлеров и нижний орнамент остаются прежними.
