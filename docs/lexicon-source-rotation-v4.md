# Lexicon Source Rotation v4 — бесконечные неповторяющиеся круги

## Правило

Лексикон никогда не заканчивается только потому, что все стартовые слова
уже использовались. Внутри одного полного круга стартовое слово не выдается
повторно, в том числе в других чатах/темах того же SQLite-хранилища.
Когда оставшихся слов нет, автоматически начинается **следующий круг**.
Если доступны разные слова, первое слово нового круга не совпадет с
последним словом предыдущего круга.

Анаграммы (источники с одинаковым набором букв) считаются одним заданием
и не повторяются в одном круге.

Активные в памяти игры не должны получать дублирование источника даже
в момент смены круга. Если единственные доступные слова используются
активными играми, раунд пока не запускается — после завершения игры
источник снова станет доступен в следующем круге.

## Хранение и переход с Lexicon v3

В существующей SQLite базе `DATA_DIR/minigames.db` используются:

- `wordgame_source_claims`: занятые слова **текущего** круга.
- `wordgame_source_cycle_state`: номер круга и последнее выбранное слово.
- `wordgame_source_cycle_history`: завершенные круги и их слова.

Данные из Lexicon v3 (`wordgame_source_claims`) сохраняются и трактуются
как уже использованные слова текущего круга. Старые `wordgame_source_cycle`
и `wordgame_round_archive` импортируются **только один раз**, при первой
инициализации состояния, чтобы они не засоряли новый круг после рестарта.

На каждом старте раунда выполняется атомарная резервация SQLite
(`BEGIN IMMEDIATE` + уникальность слова/буквенных наборов).
При ошибке БД выбор не заменяется случайным словом: нельзя пропускать
защиту от повторов.

Новые ENV и ручная миграция не нужны. Очки, подсказки, еноты, рейтинг
и модерация неизменны.

## Команда

`/lexicon_pool` показывает, сколько всего игровых стартовых слов в банке,
распределение по сложности, номер **текущего круга** и сколько
**новых в этом круге** страниц еще осталось.

## Тесты и выпуск

- Несколько последовательных полных кругов без повторов внутри круга.
- Нет повтора последнего слова на границе кругов при наличии альтернативы.
- Сохранение прогресса и номера круга после перезапуска SQLite.
- Глобальная изоляция активных игр, конкурентные запуски в разных чатах.
- Импорт старой истории только единожды, включая уже установленный v3.
- Совпадающие буквенные наборы, игра с единственным источником,
  временная недоступность истории.

Не удалять `DATA_DIR/minigames.db` при пересборке Bothost.
После зеленого CI слить PR в main и развернуть из main.
