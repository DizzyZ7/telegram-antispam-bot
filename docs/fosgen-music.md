# Fosgen Music — MVP

Музыкальный поиск с отправкой аудиофайла в личный чат Telegram. Функция выключена, пока не задан `JAMENDO_CLIENT_ID`. Используется только официальный Jamendo API и только треки с `audiodownload_allowed=true`. Скачивание из YouTube, Spotify, VK, пиратских каталогов и обход ограничений не реализованы.

## Настройка

1. Получить Jamendo API client ID на официальном портале разработчиков Jamendo.
2. Добавить `JAMENDO_CLIENT_ID` в переменные окружения Bothost.
3. Пересобрать приложение из ветки с функцией после прохождения CI и слияния.
4. Открыть личный чат с Фосгеном и отправить `/music artist title` или `/song artist title`.

Пользователь получает до 8 результатов с кнопками. Нажатие отправляет аудио через Telegram `sendAudio`, а не внешнюю ссылку. Доступ к кнопке ограничен пользователем и чатом, срок действия 10 минут. Повторные одновременные нажатия подавляются. Скачиваемый файл ограничен 20 МиБ, используется HTTPS с allowlist доменов Jamendo, редиректы отключены. Лимит одновременных скачиваний — 2 на процесс. Временные файлы не создаются.

Это первый этап: каталог ограничен Jamendo и не гарантирует наличие коммерческих исполнителей, например KEN TEE. Включать только после проверки доступности API и соблюдения лицензий конкретных треков. Кеш Telegram file_id, сохранение избранного, поиск по обращению «Фосген», пагинация и дополнительные легальные каталоги оставлены на следующие этапы. Бот не может самостоятельно изменить музыку в профиле пользователя.
